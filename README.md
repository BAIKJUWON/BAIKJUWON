## 하드웨어와 소프트웨어를 연결하는 개발자 백주원입니다.

마이크로컨트롤러와 리눅스를 기반으로
하드웨어를 직접 제어하는 임베디드 시스템을 개발하고 있습니다.

단순한 기능 구현을 넘어 장치, 통신, 운영체제를 이해하고
**안정적으로 동작하는 시스템을 만드는 개발자**를 목표로 합니다.

## 👨‍💻 소개

```text
이름       백주원
주요 분야  임베디드 시스템 · 마이크로컨트롤러 · 리눅스
주요 언어  C · C++ · Python
주요 장치  Arduino · Raspberry Pi · Raspberry Pi Pico · STM32
개발 방향  하드웨어와 소프트웨어를 연결하는 시스템 구현
```

전자회로와 마이크로컨트롤러를 기반으로
센서 데이터를 수집하고 주변 장치를 제어하는 프로젝트를 개발해 왔습니다.

아두이노, 라즈베리파이, 라즈베리파이 피코와 STM32를 활용한
임베디드 시스템 개발 역량을 키우고 있으며,
리눅스 환경에서 장치와 프로그램을 제어하는 과정에도 관심이 있습니다.

웹 개발과 보안 분야도 프로젝트와 해커톤을 통해 경험했지만,
현재는 **C·C++ 기반 임베디드 시스템 개발**을 중심으로 공부하고 있습니다.

## ⚙️ 핵심 역량

### 임베디드 시스템

* 마이크로컨트롤러 기반 하드웨어 제어
* 디지털·아날로그 센서 데이터 수집
* 서보모터, 직류모터, 발광다이오드 등 출력 장치 제어
* 조건에 따른 자동 제어 시스템 구현
* 카메라 및 통신 모듈 연동
* 장치별 라이브러리와 자료표 분석

### 시스템 문제 해결

* 하드웨어 연결 및 회로 문제 확인
* 라이브러리와 개발 보드 간 호환성 분석
* 직렬 통신을 활용한 실행 상태 점검
* 기능 단위 테스트를 통한 오류 원인 분리
* 센서 측정값과 장치 동작 오류 개선
* 반복적인 코드 수정과 시스템 안정화

### 리눅스 환경

* 우분투 기반 개발 환경 구성
* 리눅스 명령어와 파일 시스템 활용
* 컴파일러 및 개발 도구 사용
* 서버와 네트워크 환경 실습
* 센트오에스 기반 서버 환경 경험
